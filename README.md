# insta-followback-checker
Helloo, 
This Python script analyzes your Instagram data to find accounts that don't follow you back. To use it, you must first download your data from Instagram. Place the insta_checker.py script in the same folder as your followers_1.json and following.json files. Then, open a terminal or command prompt, navigate to that directory using the cd command, and run the script by typing python insta_checker.py. The terminal will then process the files and print a complete list of users who you follow but who do not follow you.

(following.json and followers_1.json from instagram settings to download account datas)
